Put memory cards here before running "pio run -t uploadfs":

  *.bin / *.vmu   whole 128 KiB VMU cards (what the website downloads, and what Dreamcast emulators
                  keep as vmu_save_A1.bin and the like)
  *.vms / *.dci   single games or saves; the device wraps each one in a card of its own at start-up

Nothing in this folder except this note is published (see .gitignore).
